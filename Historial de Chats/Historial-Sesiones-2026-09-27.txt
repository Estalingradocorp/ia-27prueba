[ORIGEN]
En el chat con IA27, el modelo sugirió capacidades para volverse un agente

[MARCADORES IMPLEMENTADOS]
- [[READ]] ruta    → lee archivo (máx. 4000 chars) o lista carpeta.
                     Libre dentro del área de trabajo; fuera pide permiso.
- [[CMD]] comando  → ejecuta PowerShell (cwd del proyecto, timeout 30 s).
                     SIEMPRE pide confirmación s/n. Patrones destructivos
                     (Remove-Item -Recurse -Force, format, shutdown, etc.)
                     muestran advertencia roja extra.
- [[WRITE]] ruta :: contenido → crea/reemplaza archivo. SIEMPRE pide s/n
                     con vista previa del contenido.

[ARQUITECTURA]

  al modelo.
- Buffer anti-fugas existente cubre los nuevos marcadores automáticamente.

SESIÓN B — Bug: el modelo alucinó la creación de archivos
--------------------------------------------------------------------------------

[SÍNTOMA REPORTADO POR EL USUARIO]
La primera escritura funcionó (pidió permiso, creó prueba.txt), pero después
el modelo dijo "He creado el archivo mejoras.txt" DOS veces sin crear nada.
Además prueba.txt quedó contaminado: contenía la frase del asistente
"¿Necesitas realizar alguna otra acción?" dentro del archivo.

[CAUSAS RAÍZ]
1. WriteRequestPattern capturaba [\s\S]*$ → TODO hasta el fin del mensaje,
   incluido el chatter posterior al contenido.
2. El 7B aprendió del historial que "afirmar la creación" era la respuesta
   esperada, y dejó de emitir [[WRITE]] en contenidos largos.
3. ExplicitWriteIntent exigía la palabra "archivo" + cuerpo literal; no
   capturó: "crea un tecto en esa carpepeta con el titulo mejoras con toda
   esta data" ni "si crea un txt con ese texto aqui C:\..." (typos + ruta en
   otra posición + cuerpo referencial).

[FIXES APLICADOS]
1. Cierre obligatorio [[END]]: [[WRITE]] ruta :: contenido [[END]].
   Sin [[END]] → marcador malformado, NO se crea nada, reintento forzado.
2. Anti-alucinación (WriteClaimPattern / CmdClaimPattern): si el modelo
   afirma "he creado el archivo / ejecuté el comando" sin haber usado la
   herramienta en ese turno → se descarta la respuesta falsa, se inyecta
   orden estricta de reemitir con marcador (máx. 2 reintentos).
3. ToolsPolicy reforzada: ejemplo multi-línea realista, prohibición explícita
   de afirmar creación sin marcador, solo se puede afirmar citando la
   confirmación [SISTEMA · archivo creado: ruta, N bytes].
4. ExplicitWriteIntent ampliado: sustantivos archivo/fichero/txt/texto/tecto/
   nota/documento; fillers iniciales (si/dale/ahora/ok/y); ruta absoluta o
   relativa en CUALQUIER posición; cuerpo referencial ("con toda esta data",
   "ese texto") → no ejecuta, inyecta orden al modelo de emitir [[WRITE]]
   con contenido del contexto.
5. lastToolPath: la sesión recuerda la última ruta de herramienta; pedidos
   sin ruta ("en esa carpeta", "con el título mejoras") se resuelven ahí.

[VERIFICACIÓN DE REGEX (PowerShell, motor .NET)]
- "[[WRITE]] C:\x\mejoras.txt :: Titulo\n[[END]]\n¿Algo mas?" → body limpio ✓
- "[[WRITE]] ... :: sin cierre" → sin match (protegido) ✓
- Frases reales del chat (con typos) → todas detectadas ✓
- "no pude crear el archivo porque denegaste" → NO dispara claim ✓

SESIÓN C — Modo Harness (bucle agéntico propio)
--------------------------------------------------------------------------------

[PEDIDO]
"le podemos instalar HARNESS AGENT?" → aclarado: bucle agéntico propio
(plan → ejecutar → verificar → iterar), no la plataforma Harness.io.

[IMPLEMENTACIÓN]
- Nuevo comando: /harness <objetivo> (alias: /agente)
- RunHarnessAsync en TerminalApplication.cs:
  1. Inyecta [SISTEMA · MODO HARNESS ACTIVADO] con el objetivo.
  2. Cada paso el modelo hace UNA cosa: plan numerado / UNA herramienta /
     [[DONE]] + resumen final.
  3. Tras cada herramienta recibe el resultado real y debe verificarlo.
  4. Límite: HarnessMaxSteps = 15 pasos; al llegar, cierra con aviso.
  5. Marcador malformado → no ejecuta nada, reintenta el paso.
  6. Buffer anti-fugas replicado: ningún marcador se imprime.
  7. Ctrl+C aborta en cualquier momento; permisos s/n intactos para
     [[CMD]] y [[WRITE]].
